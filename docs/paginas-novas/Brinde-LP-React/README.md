# Landing Page Brinde — Marmoristas

Versão React da landing page aprovada da Agência Brinde.

## Como executar

1. Instale o Node.js 20 ou superior.
2. Abra o terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço exibido no terminal.

## Gerar a versão de produção

Execute `npm run build`. Os arquivos finais serão gerados na pasta `dist`.

## Personalização

- Conteúdo e estrutura: `src/App.jsx`
- Estilos e responsividade: `src/styles.css`
- Logos, vídeo e poster: `public/assets`
- Link do WhatsApp: constante `WHATSAPP_URL` no início de `src/App.jsx`

O player possui tratamento específico para permanecer dentro do mockup em dispositivos móveis compatíveis.
