# Exact Clone Landing

O arquivo HTML anexado é a versão CANÔNICA e APROVADA da landing page ConstruLead da Agência Brinde.

Quero transformar exatamente este HTML em um projeto editável dentro do Lovable.

REGRAS OBRIGATÓRIAS:

NÃO redesenhe a página.

NÃO recrie o design.

NÃO altere textos.

NÃO altere imagens.

NÃO altere tipografia.

NÃO altere cores.

NÃO altere espaçamentos.

NÃO altere o layout desktop.

NÃO altere o layout mobile.

NÃO altere a dobra "Como funciona o ConstruLead".

NÃO altere o FAQ.

NÃO altere formulários.

NÃO faça melhorias visuais.

A aparência atual está aprovada.

Neste primeiro passo, faça somente:

1. importe/reproduza fielmente o HTML anexado dentro do projeto;

2. preserve integralmente HTML, CSS e estrutura visual;

3. faça a página abrir no preview;

4. não tente corrigir os vídeos ainda.

Existe um problema conhecido nos vídeos, mas vamos corrigir isso separadamente depois que a página estiver reproduzida corretamente.

Use o HTML anexado como fonte da verdade.
